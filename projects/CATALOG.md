# 金融学习与真实案例项目调研 v0.1

调研日期：2026-11-12。以下是依据公开一手资料设计的学习项目，不是已执行研究或投资建议。未下载、运行作者模型，不声称复现其结果。课时为教学估计，按每次约45–60分钟计算。

筛选原则：可追溯输入、明确推理、可改变假设、可检验结果、能说明失效条件。公开资料不等于允许再分发完整数据；仓库保存链接、原创摘要与自行计算，避免搬运全文或受限数据。

## P01：同一看涨观点，为什么会选不同工具？

问题：温和上涨、大涨、先跌后涨分别适合如何表达？
输入：先用透明模拟数，再读取选定交易所一份当前合约与同一时点报价。
步骤：比较指数敞口、期货、看涨期权、看涨价差；先统一名义敞口，再比较现金/保证金和压力损失。不能把投入金额相同误当风险相同。
成果：到期收益表、持有期情景表、工具选择备忘录。
过关：能解释为什么“便宜”“杠杆高”不自动意味着更优。
来源入口：[中金所投教学堂](https://www.e-cffex.com.cn/web/gzqqgame/)、[上交所期权课程](https://edu.sse.com.cn/college/qqxytj/kczx/)。
边界：上交所课程涉及股票/ETF期权，不能替代中金所股指期权规则；真实合约参数需另外逐项核验。本次核对了学习入口，未逐课审阅。

## P02：从复制组合理解定价，再观察对冲误差

问题：为什么期权价格不只取决于主观涨跌概率？
步骤：一周期二叉树 → 多期树 → Delta/Gamma/Theta/Vega 的有限差分 → 离散对冲。初期不引入随机微积分。
成果：一个小型计算表或 notebook，记录模型参数、理论值与冲击后的完整重估。
过关：知道 Greeks 是局部近似；知道跳空、交易成本、波动率变化会造成对冲误差；区分现实概率与定价测度。
来源：[Damodaran 估值材料入口中的期权定价应用](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valuation/val.htm)；课程安排与实验由我们设计。
边界：公司实物期权案例只辅助理解定价，不等于指数期权实盘模型；具体公式在开课时逐项给定验证。

## P03：DCF + 反向 DCF——把“好故事”翻译成可质疑的数字

最推荐的估值项目。Damodaran 的公开课程有讲义、表格、练习和公司估值项目，可用来重建模型，而非照抄目标价。
问题：当前价格要求多高的收入、利润率、再投资效率和持续时间？这些假设能否同时成立？
步骤：读一份成熟企业简化财务数据 → FCFF 预测 → WACC/终值 → 股权桥 → 敏感性 → 固定其他假设反求一个变量。反向 DCF 没有唯一的隐含故事。
成果：估值表、假设树、三情景、最值得验证的两项经营证据。
过关：解释增长与再投资如何联动，避免把增长看作免费；不能用终值占比大自动判模型错误，要检查其经济假设。
主来源：[NYU 估值课程](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/equity.html)。
真实案例候选：[Tesla 2023-01 估值文章](https://aswathdamodaran.blogspot.com/2023/01/tesla-in-2023-return-to-reality-start.html)。
核验状态：课程主页已打开；Tesla 文章的标题、日期与内容摘要可检索，但全文直接访问遇到限制，配套表格未下载。因此它是待完整读取的候选，不是已经审计完成的模型。
迁移：把“公司是否便宜”进一步拆成指数盈利与折现率情景；不以估值直接预测短期期权收益。

## P04：指数盈利、估值与利率情景

问题：指数上涨究竟需要盈利改善，还是折现率/风险溢价下降？
步骤：选择一个指数；核对成分和权重时点；拆行业盈利贡献；做盈利 × 估值情景；写出哪个新增证据会改变观点。
成果：一页指数情景备忘录。输入包括盈利口径、股息、利率、行业权重和时点。
过关：不能用成分股 PE 简单平均冒充指数 PE；不把指数点位乘“某家公司EPS”。
来源：P03 的估值方法；[FRED/ALFRED 版本区别](https://fred.stlouisfed.org/docs/api/fred/fred_vs_alfred.html)辅助宏观时点管理。
尚缺：选定市场后再确定指数公司方法文档与历史成分数据。该项目是框架设计，尚未完成数据可用性验证。

## P05：市场对波动的报价，和后来发生的波动

问题：隐含波动看上去贵，是否真的能获得卖方优势？
步骤：统一期限、交易日/自然日、价格收益口径与年化；记录 t 时点指标，与 t 之后同期限 RV 配对；用不重叠窗口或处理序列相关；观察不同压力阶段。
成果：配对数据表、散点/分组统计、假设与反例。
来源：[Cboe VIX 历史数据](https://www.cboe.com/tradable_products/vix/vix_historical_data)、[VIX 产品说明](https://www.cboe.com/tradable-products/vix/)。
过关：VIX 是指标，不能直接买入 VIX 现货；VIX 与 RV 差值不是某个期权策略的已实现利润。优先在方差尺度比较，必要时明确平方根转换误差与测度差异。
边界：本次只核对公开历史数据入口，没有下载样本或估计溢价。没有历史 bid/ask、对冲和成本数据时，不做盈利结论。

## P06：审计备兑与 PutWrite，而非把权利金当利息

问题：较平滑的净值，是否只是降低上涨参与或承担特定尾部风险？
材料：[Cboe 对 BXM/BXMD/PUT/CMBO 的研究介绍](https://www.cboe.com/insights/posts/benchmark-indices-series-income-generation-and-smoother-returns-with-cboes-bxm-bxmd-put-and-cmbo-indices)（2021-07-20）；[保护性策略 PPUT/CLL/CLLZ](https://www.cboe.com/insights/posts/benchmark-indices-series-hedging-downside-exposure-with-pput-cll-and-cllz-indices)。
步骤：读取指数方法学 → 分开权利金与总收益 → 对齐股息/现金利息/名义敞口 → 牛市、熊市、反弹分段比较 → 加成本/资本占用。
成果：策略审计表；说明什么目标适合某结构，不能只选最高 Sharpe。
过关：识别备兑收益上限与卖 put 的下跌暴露；不把交易所宣传中的历史表现当未来保证。
核验状态：研究介绍已打开；完整规则版本与原始时间序列在开题时再下载核验，尚未复现绩效。

## P07：2022 年6月 FOMC——先冻结信息，再做判断

问题：政策决议与市场预期之差，如何影响指数和期权？
主材料：[2022-06-14/15 FOMC 会议资料](https://www.federalreserve.gov/monetarypolicy/fomcpresconf20220615.htm)、[当日声明 PDF](https://www.federalreserve.gov/monetarypolicy/files/monetary20220615a1.pdf)、[ALFRED](https://alfred.stlouisfed.org/)。
步骤：分别冻结会前、声明后、发布会后三个时点；用户先写情景；再揭示新增信息与行情。会议纪要属于之后公布的材料，禁止偷渡进会前信息集。
成果：时间线、事前决策卡、事后归因，区分政策冲击和其他共同发生的消息。
过关：没有当时利率期货/调查等证据时，不能把自己的预期当“市场共识”；不从单一事件推出稳定 alpha。
数据缺口：历史完整期权链与可成交 bid/ask 未确认。早期只研究机制；用模拟报价必须明确标注。

## P08：2018 年2月5日波动率产品危机

最推荐的风险案例。核心不是“看空的人输了”，而是持仓规则如何反过来改变交易需求。
主材料：[BIS 专题](https://www.bis.org/publications/equity-market-turbulence-5-february-role-exchange-traded-volatility-products)（2018年3月；图表于3月21日更正）。
文章研究杠杆与反向波动率 ETP 的每日再平衡，以及这些交易对当日市场波动的放大作用。
步骤：先区分 SPX 期权、VIX、VIX 期货和 ETP；用明确模拟资金规模演示目标杠杆再平衡；再对照 BIS 的机制解释与证据。
成果：产品资产负债/敞口表、再平衡计算、价格反馈关系图、什么信息仍无法识别。
过关：不能把 VIX 上涨直接视为 VIX 期货同幅上涨；不能把短期产品当长期静态做空波动头寸。
边界：BIS 是事后机制分析，不是可事前复制的交易建议。学习解释与证据强度，不用危机故事代替样本研究。

## P09：2022 年英国 LDI 危机

主材料：[英格兰银行 2022年12月金融稳定报告，第5节](https://www.bankofengland.co.uk/financial-stability-report/2022/december-2022)。
问题：长期资产负债匹配有道理，为什么短期仍会被迫卖出？
报告描述收益率急升下的抵押品追缴、被迫出售国债及市场反馈。
步骤：分别列养老金负债估值、LDI 头寸、可用现金；用模拟利率冲击计算抵押品需求；讨论“整体偿付能力”与“当日支付能力”。
成果：保证金压力情景与现金缓冲需求，不从久期数字直接推断无限流动性。
迁移：股指期权卖方的到期判断可能正确，但途中保证金约束可使其无法持有到期。只迁移机制，不照搬债券参数。

## P10：最小历史时点环境

围绕 P07 已完成的小案例建设，避免先造大型平台。
数据字段：observation_time、release_time、available_at、retrieved_at、vintage、source_url、unit、timezone。没有细粒度时戳时保留未知；ALFRED 的日期版本不能自动满足分钟级事件回放。
功能：指定 cutoff → 返回当时可获得的原始数据与证据 → 用户/Agent 写决策 → 解锁事后资料 → 归因。
成果：一个事件、两个时点、可重放输入包；事实正确性与决策质量分别评价。
来源：[ALFRED API说明](https://fred.stlouisfed.org/docs/api/fred/alfred.html)、[vintage date定义](https://fred.stlouisfed.org/docs/api/fred/series_vintagedates.html)。
完成标准：明确阻止未来信息；支持修订版本；没有数据时返回缺口，不能悄悄使用今天修订后的数。

## 暂缓内容

- 大而全的并购/困境重组：可以拓展金融认知，但不是股指期权起步的关键依赖。
- 先搭自动交易 Agent 或大回测框架：先完成一份人工可解释的研究。
- 仅用 Sharpe、胜率排名挑策略：必须理解收益来源、尾部、资本与成本。
- 把外部报告的判断当标准答案：计算可以核对，投资假设要允许竞争性解释。

推荐起步组合：P01（表达）+ P03（估值）+ P08（风险），P02/P05 补足期权定价与统计基础。此排序是教学判断，不是收益排序。
